# Configure Dynamic Inventory

## Overview

### Create the EC2 using Terraform
### Write Ansible AWS EC2 Plugin to dynamically sets inventory of EC2 inventroy. EC2 servers that Ansible should manage, instead of hard-coding server addresses in Ansible inventory file.

## Prerequisites: 
### -- Install Ansible onto the PC
### -- Install Terraform onto the PC and have the Terraform Provider block connected the AWS.

# Steps:

## 1. We created the EC2 Instance using the Terraform.
## 2. We write the Ansible AWS EC2 to dynamically set the inventory of EC2 server that Ansible should manage.
